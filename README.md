# Hi, I'm Albert

**Embedded Software / Firmware Engineer** - low-power, connected devices in C/C++

I build firmware for battery-powered and connected products, from board bring-up to field updates. 4+ years on ESP32, MSP430 and TI CC26xx with ESP-IDF, FreeRTOS, TI-RTOS and Zephyr, plus the mobile apps and backend around the device when a project needs them.

Most of my work lives in private client and employer repositories, so this page summarizes it.
